RESET Pilates Studio Website

1. Project Overview

RESET Pilates Studio is a student multi-page website project designed to introduce the studio, explain its Pilates services, display pricing, and allow potential clients to make enquiries or contact the studio.

The website provides information about RESET Pilates Studio and allows visitors to easily navigate between the Home, About Us, Services, Enquiries and Contact Us pages.

⸻

2. Project Purpose

The main purpose of the website is to create an online presence for RESET Pilates Studio and make important information available to potential and existing clients.

The website aims to:

* Introduce RESET Pilates Studio and its services.
* Explain the studio’s story, mission and vision.
* Provide information about Mat Pilates, Reformer Pilates and Private Sessions.
* Display class pricing.
* Allow visitors to enquire about a trial class.
* Provide the studio’s locations, opening hours and telephone numbers.
* Make the website simple and easy to navigate.

⸻

3. Target Audience

The target audience for RESET Pilates Studio includes:

* People who are interested in Pilates.
* Beginners who want to start Pilates.
* Experienced Pilates clients.
* People looking for low-impact exercise.
* People interested in Mat Pilates.
* People interested in Reformer Pilates.
* Clients looking for private Pilates sessions.
* Potential clients in the Rosebank and Midrand areas of Johannesburg.

8. How to Run the Website

To run the website:

1. Open the RESET Pilates Studio project folder.
2. Make sure all five HTML files are inside the main folder.
3. Make sure the images folder is inside the main project folder.
4. Check that the image filenames match the filenames used in the HTML code.
5. Open index.html in a web browser.
6. Use the navigation menu to move between the pages.
7. Test the forms and links on each page.

10. Accessibility

Accessibility is important because the website should be usable by as many people as possible.

The website includes:

* Alternative text for images using the alt attribute.
* Labels for form fields.
* Clear headings.
* Simple navigation.
* Readable text.
* Meaningful link text.
* Logical page structure.

For example:

<img src="images/studiologo.png" alt="RESET Pilates Studio Logo">

The alt attribute provides a description of the image for users who may use screen readers.

11. Design Plan

The website will have a calm, clean and modern Pilates-inspired design.

Colour Scheme

The proposed colour scheme includes:

* Sage green.
* Cream.
* White.
* Charcoal/dark grey.

These colours were chosen because they create a calm, natural and relaxing appearance that suits a Pilates and wellness business.

Typography

A clean and readable font such as Aptos or Arial can be used for the website.

Large headings will be used to make important information easy to identify.

User Experience

The website will provide:

* Simple navigation.
* Consistent page layouts.
* Clear headings.
* Easy-to-read information.
* Clear calls-to-action.
* Easy access to contact and enquiry information.
* A responsive design for different screen sizes.

This website is currently a student prototype.

The website does not currently have an online payment system or live booking system.

The contact details and studio information are project information and should be verified before the website is used commercially.
